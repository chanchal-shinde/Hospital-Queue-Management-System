# Hospital-Queue-Management-System
A Java Swing and MySQL based Hospital Queue Management System with role-based login, patient token generation, queue tracking, doctor management, patient history, and daily statistics.
## Features

### Admin
- Add Doctor
- View Doctors
- View Users
- Hospital Statistics
- Patient History

### Receptionist
- Register Patients
- Daily Token Generation
- Search Patients by Name
- View Today's Queue
- Patient History
- Daily Statistics

### Doctor
- View Assigned Patients
- Call Next Patient
- Complete Consultation
- Real-time Queue Updates

### General
- Role-Based Login
- MySQL Database Integration

 ## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Object-Oriented Programming (OOP)
- Daily Token Reset
- Patient Visit History
- Queue Status Tracking

## Database Tables

- users
- doctors
- patients
